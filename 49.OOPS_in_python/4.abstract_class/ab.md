# Abstract Class:

An abstract method is a method that is declared but has no implementation in the parent class. It forces every child class to provide its own implementation.

A class that cannot be instantiated on it's own; meant to be subclassed.
They can contain abstract methods, which are declared but have no implementation.

Abstract class benefits:

1. prevents the instantiation of the class itself.
2. Requires children to use inherited abstract method.
