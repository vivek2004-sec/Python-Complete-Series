Object Oriented Programming in Python

OOP is a way of writing code by
creating OBJECTS that have
properties and behaviors!

Instead of writing functions everywhere
you create CLASSES that contain
everything related to one thing!

Real Life Example:

Think of a CAR:

Properties (what it HAS):
→ color
→ brand
→ speed
→ fuel

Behaviors (what it DOES):
→ start()
→ stop()
→ accelerate()
→ brake()

In OOP:
Properties → Variables (attributes)
Behaviors → Functions (methods)
