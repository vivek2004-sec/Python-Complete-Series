# Simple Rule:

if **name** == "**main**":
→ Put code here that should ONLY run
when you run THIS file directly

    → Will NOT run when someone
      imports your file

# Real World Use:

Big projects have many files
Each file has functions

if **name** == "**main**"
makes sure your test code
does not accidentally run
when someone imports your file!

This is how PROFESSIONAL
Python code is written! 💪
