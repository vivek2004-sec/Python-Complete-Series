File Opening Modes:

"r" → Read only
"w" → Write (overwrites existing content)
"a" → Append (adds to end of file)
"x" → Create new file
"r+" → Read and Write
"w+" → Write and Read (overwrites)
"a+" → Append and Read
"rb" → Read binary file
"wb" → Write binary file
