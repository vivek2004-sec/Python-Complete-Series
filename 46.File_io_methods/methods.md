File Handeling Methods:

read() → Reads entire file
readline() → Reads one line at a time
readlines() → Reads all lines as a list
write() → Writes string to file
writelines() → Writes list of strings to file
close() → Closes the file
seek() → Moves to specific position in file
tell() → Returns current position in file
truncate() → Removes content after given position
flush() → Flushes internal buffer to file
readable() → Returns True if file is readable
writable() → Returns True if file is writable
